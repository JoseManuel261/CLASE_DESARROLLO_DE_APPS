Manipulación del DOM

Aprende a dar vida a tus páginas web. Esta lección interactiva te enseñará a usar JavaScript para modificar el contenido, estilo y estructura de tu HTML de forma dinámica.

Conceptos Clave

El DOM (Document Object Model) es la estructura de tu página. JavaScript te da las herramientas para ser su arquitecto. Haz clic en cada categoría para explorar los métodos fundamentales.

1. Selección de Elementos

Para manipular un elemento, primero debes encontrarlo en el DOM.

  • getElementById('id'): El más rápido, busca por ID único.
  • querySelector('css'): Versátil, encuentra el primer elemento que coincida con un selector CSS.
  • querySelectorAll('css'): Poderoso, devuelve todos los elementos que coincidan.

2. Modificación de Elementos

Una vez seleccionado, puedes cambiar casi todo sobre un elemento.

  • .textContent: Cambia el contenido de texto.
  • .style.property: Modifica estilos CSS directamente.
  • .classList.add/remove: Añade o quita clases CSS para cambiar estilos.

3. Creación y Eliminación

Crea nuevos elementos desde cero y añádelos o elimínalos del DOM.

  • createElement('tag'): Crea un nuevo nodo HTML (ej: 'div', 'li').
  • .appendChild(child): Inserta un elemento como el último hijo de otro.
  • .removeChild(child): Elimina un elemento hijo.
